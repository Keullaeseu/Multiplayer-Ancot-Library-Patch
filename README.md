# Multiplayer Ancot Library Patch

A RimWorld Multiplayer compatibility patch for [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276).

This mod is designed to improve multiplayer synchronization when playing with the [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276) mod and RimWorld Multiplayer.

## Features

- Adds multiplayer compatibility for [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276).

## Requirements

- RimWorld
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)

The host and every connected player must use compatible versions of all required mods.

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. RimWorld Multiplayer
5. [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
6. [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)

The patch should load after both RimWorld Multiplayer and [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276).

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)
- [Multiplayer Ancot Library Patch](https://github.com/Keullaeseu/Multiplayer-Ancot-Library-Patch/releases/latest)
- All required Ancot Library dependencies

The host and all connected clients should use the same:

- RimWorld version
- RimWorld Multiplayer version
- Ancot Library version
- Multiplayer Ancot Library Patch version
- Mod configuration
- Mod load order

Do not add, remove, update, or reorder mods while players are connected to the same multiplayer session.

## Compatibility

This patch is intended to provide multiplayer compatibility for [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276).

It does not replace:

- [RimWorld Multiplayer](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745)
- [Ancot Library](https://steamcommunity.com/sharedfiles/filedetails/?id=2988801276)

## Known Limitations

- Compatibility may be affected by future RimWorld updates.
- Compatibility may be affected by future updates to RimWorld Multiplayer or Ancot Library.
